# Experiment Documentation

This directory contains the methodology and narrative documentation for observability experiments.

Each experiment should be understandable and repeatable without relying on undocumented manual actions. Use `template.md` when introducing an experiment and link to the executable definitions under `experiments/` and any retained outputs under `results/`.

Experiment documentation should distinguish:

- The question or hypothesis being evaluated.
- The controlled platform and application configuration.
- The workload and introduced condition.
- The telemetry signals and variables observed.
- The execution procedure.
- The resulting evidence and interpretation.
- Threats to validity and known limitations.

Documentation should be completed before drawing conclusions from an experiment.
